> The world's first actively anti-design, emotionally unstable, chaos-engineered replica of Figma.

### Project Description

**Useless Figma** is a pixel-perfect, hyper-detailed satirical replica of Figma's dark-mode web editor that actively fights the user at every turn. Instead of helping you create clean, accessible, modern UI, it enforces maximum cognitive overload, retinal damage, and emotional turmoil. Shapes refuse to be drawn straight, frames rearrange themselves every 30 seconds, layers have feelings and lock up until flattered, and passive-aggressive sticky notes written in authentic Malayalam pop in to judge your design decisions.

---

### The Problem (that doesn't exist)

Modern design tools like Figma make it entirely too easy to create clean, aligned, accessible, and user-friendly products. Designers have grown complacent with 8px grids, harmonic color palettes, predictable auto-layout, and polite design systems. 

Where is the thrill of suffering? Where is the panic of a button that flees from your mouse cursor? Why should computers work *for* us when they could actively undermine our visual taste?

---

### The Solution (that nobody asked for)

We engineered **Useless Figma** — a complete anti-productivity suite featuring:
- **Permanent Tilt**: Every rectangle, circle, frame, or text snaps into an awkward, non-zero angle. Clean 90° angles are prohibited.
- **30-Second Auto-Layout Chaos**: An automatic visual hierarchy engine that reshuffles all frames into random spirals, piles, or corner clusters every 30 seconds.
- **Clashing Color Picker**: Harmonious colors are disabled. The tool only offers eye-searing, neon-mud clashes (*Ugly Green, Painful Pink, Mud Brown, Too Bright Yellow*).
- **Passive-Aggressive Malayalam Notes**: Authentic Malayalam critiques that pop in directly over your work to block your view (*"ഇതെന്തൊരു ഡിസൈൻ ആണ്? എന്റെ കൊച്ചുമോൻ ഇതിലും നന്നായി വരയ്ക്കും"* / *"What kind of design is this? My grandson draws better"*).
- **Sentient Layers & Layer Therapy**: Layers get offended if ignored and refuse to be selected until you open a therapy dialogue and flatter them.
- **Gravity Mode (🪐)**: Real-time 2D rigid-body physics where frames tumble down, bounce off the floor, and can be flung around with mouse momentum.
- **Infinite Zoom-Out Tool**: Zoom in, zoom out, and scroll wheels only ever zoom out until your canvas becomes a microscopic speck in the Cosmic Void.
- **AI That Makes Things Worse (✨)**: One-click conversions into 12-column corporate table nightmares, fake Web3 gas fee gates, or Comic Sans chaos.
- **Break Screen with 80s Elevator Music**: Locks the screen after 5 minutes and plays synthesized Bossa Nova elevator Muzak using the Web Audio API.
- **Cursed Exports**: Export your design to Morse Code (with real audio beeps), ASCII art, or a printable physical Paper Airplane template.
- **Official Certificate of Bad Design**: Live points tracking that awards you a printable diploma signed by Dylan Field.

## Implementation

### Installation

No complex dependencies, build steps, or node_modules required! Simply clone the repository:

```bash
git clone https://github.com/SarayuSuresh18/useless-figma.git
cd useless-figma
```

### Run

Run with any local HTTP server (such as Python's built-in server or Node):

**Using Python:**
```bash
python -m http.server 8181
```

**Using npx:**
```bash
npx -y serve -l 8181 .
```

Then open your browser and go to:
👉 **`http://localhost:8181/index.html`**

## Key Features Breakdown

### 1. Actively Anti-Design
- **Always Tilted**: Every shape drawn (Rectangle, Circle, Frame, Text) automatically receives a randomized awkward tilt (+8.4°, -11.2°, etc.) with lopsided border-radii.
- **Auto-Layout Chaos**: Every 30 seconds, an automatic timer reshuffles frames across the canvas for "better visual hierarchy."
- **Zero-Harmony Color Picker**: Calculates canvas colors and exclusively offers clashing, retina-scorching palettes.
- **Malayalam Pop-In Sticky Notes**: Pop-in critique notes written in Malayalam with English subtitles that pop up right on top of active elements to cover them up.
- **Version History Rollback**: Footer widget with a "Rollback" button that reverts the canvas to `v0.3 (The Ugliest Version)`.

### 2. Over-Engineered Nonsense
- **Bad UI Kit (Assets Panel)**:
  - *Unclickable Button*: Moves away or has a microscopic hit area.
  - *Sneaky Popup*: Pre-checked $9,999 subscriptions with an invisible close button.
  - *Confusing Form*: Upside-down labels and strange symbols.
  - *Hard to Read Card*: Yellow text on white background with 400% letter-spacing.
- **AI 'Help' That Makes Things Worse**:
  - *Make it Corporate*: 12-column table with EBITDA charts and SAML approval walls.
  - *Crypto Mode*: NFT badges with a 4.8 ETH MetaMask gas fee gate.
  - *Work Mode*: Covers buttons with red `[BLOCKED]` Jira tickets.
  - *Make it POP*: Comic Sans font with massive 25px offset neon drop-shadows.
- **Bad Export Formats**:
  - *Morse Code*: Translates canvas items into Morse code telegraph signals with interactive audio beeps.
  - *ASCII Art*: Renders elements into monospace 80-column text drawings.
  - *Paper Airplane Blueprint*: Interactive SVG origami guide with print instructions to throw your design at leadership.

### 3. Meta & Self-Aware Uselessness
- **Design Taste Critic**: Floating toast that judges every action (*"4px rounded corners? Very 2012"*).
- **Take a Break (Lock Screen)**: Mandatory lockout that plays synthesized 80s elevator Muzak with spinning vinyl and dancing audio equalizer bars.
- **Bad Designer Award**: Live points counter tracking your bad design deeds. View and print your official **"Certificate of Bad Design"** with gold seal and signatures!

### 4. Pure Chaos Mechanics
- **Gravity Mode (🪐)**: Toggles physics on the canvas. Frames tumble downwards, bounce off the floor, and can be tossed across the viewport.
- **Sentient Layers (Layer Therapy)**: Layers have feelings! If you try to select an ignored layer, it opens a therapy session where you must flatter it to unlock editing.
- **Infinite Zoom-Out Tool**: Zoom in (+), zoom out (-), and wheel scrolling all exclusively zoom out, until you enter the Interstellar Void at 0.00001% zoom.
